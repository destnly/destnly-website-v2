# Destnly — Static Final Site

Static website only: HTML, CSS, JavaScript and image assets. No Python or runtime content download needed.

Run locally with `python3 -m http.server 8080` from this directory (Python is a test web server, not a website dependency).

Direct routes: `/privacy`, `/terms`, `/child-safety`, `/account-deletion`, `/contact`. Static directory indexes are included and Netlify `_redirects` keeps the exact clean URLs on deployment. Legacy `.html` addresses also work.

The four legal texts were transcribed from the published destnly.com pages on 2026-11-22. IMPORTANT: the original pages use Cloudflare protected email-address markup that could not be recovered from the public text view; `contact@destnly.com` (confirmed on the public Google Play listing) has been used for all contact emails. The wording and sections otherwise follow the live texts but have NOT been byte-for-byte compared with the original HTML. Legal owner must verify these contact addresses and the full wording against the original website before replacing the production policies.

The existing homepage, motion effects, app screenshots and interest imagery were left unchanged.
